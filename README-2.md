# MusikFlo — Sheet Music Studio & Composer

A browser-native music composition, notation and playback studio built with React, TypeScript,
Vite, VexFlow, Tone.js and Tailwind CSS.

**This document has been superseded by [README.md](./README.md)**, which covers the current
stack, scripts, architecture, coordinate and pitch models, theme tokens, routing, storage,
testing and deployment.

A previous version of this file described a Python/Streamlit implementation that does not exist
in this repository. It has been replaced so the documentation matches the shipped code.
